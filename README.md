# ⚔️ 吕蒙智能体

一个基于 DeepSeek API 的历史人物 AI 对话系统，以三国时期东吴都督吕蒙的身份与用户对话。

## 在线体验

[点击访问](https://你的streamlit链接.streamlit.app)

## 功能特点

- 🎭 以吕蒙的第一人称视角对话
- 📚 基于《吕蒙长编》史料检索
- 💬 保持半文半白的古风语调
- 🧠 智能记忆历史对话上下文

## 技术栈

- Python 3.8+
- Streamlit
- DeepSeek API
- Pandas (Excel 数据处理)

## 本地运行

```bash
pip install -r requirements.txt
streamlit run lv_meng_web.py
```

## 数据源

- `吕蒙长编.xlsx` - 吕蒙生平史料数据库
